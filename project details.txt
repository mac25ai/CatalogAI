  Engineer handover checklist

  1. Real Claude API chatbot — in routers/chatbot.py, replace mock_response() (marked # ENGINEER:). pip install anthropic, model claude-sonnet-4-6, inject
  the full product catalogue + FAQs as system context, key from ANTHROPIC_API_KEY.
  2. Railway deployment — add railway.toml with the uvicorn start command, connect the GitHub repo, set ANTHROPIC_API_KEY in the Railway dashboard.
  3. Database migration (optional, Stage 1) — JSON files in clients/ → PostgreSQL (tables: clients, categories, products, faqs). The config_loader.py
  interface stays the same; only the data source changes.
  4. Proper authentication — hash the passwords in admin_credentials.json (or JWT/OAuth) and move the session secret in main.py to an environment variable.

  Two decisions I made along the way

  - The landing page CTA uses a placeholder WhatsApp number 919999999999 — swap in your real MAC25AI number in templates/landing.html (2 places).
  - Demo images use via.placeholder.com in each client's brand colors, as the spec allows. For real clients, paste imgbb.com URLs into the admin panel.
